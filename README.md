# Simple Linear Regression (Google Colab)

This project implements **Simple Linear Regression** using Python and scikit-learn.  
It predicts a dependent variable (y) based on one independent variable (x).  

## 📌 Steps
1. Load dataset
2. Visualize data
3. Train linear regression model
4. Evaluate using R² score

## 📊 Results
- R² Score: 0.37
- Shows moderate correlation between features.

## 🚀 Tech Stack
- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
